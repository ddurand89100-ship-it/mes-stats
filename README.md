# Mes stats

Le tableau de bord financier du joueur pro : chaque entrée d'argent (salaire, prime, sponsor, droit à l'image, revenu annexe) est répartie automatiquement entre quatre enveloppes : à vivre, coussin de sécurité, épargne transition, cotisations et impôts.

- Appli web installable sur téléphone et ordinateur, utilisable hors ligne.
- **Les données restent sur l'appareil du joueur.** Aucun compte, aucun serveur, aucune collecte.
- Sauvegarde et restauration par fichier, depuis les Réglages.

Outil pédagogique : il ne remplace pas un conseil financier, fiscal ou juridique.

Conçu par Damien Durand.
